# seladorr.github.io

My personal site — live at [seladorr.github.io](https://seladorr.github.io).

A single hand-written page (HTML + CSS, no framework) served through GitHub Pages'
Jekyll build. Tabs for home, projects, experience, writing, and travels, plus a light/dark
theme toggle.

- `index.html` — the page
- `_config.yml` — Jekyll/site config
- `pics/` — profile and travel photos
- `cv.pdf` — résumé

To edit, change `index.html` and push; GitHub Pages rebuilds automatically.
